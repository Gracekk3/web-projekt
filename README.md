# Fanouškovský web Arsenal FC – We Are The Gunners

## Autor
Gracjan Čemeryš

---

##  Stručný popis projektu
Fanouškovský one-page web věnovaný fotbalovému klubu **Arsenal FC**. Stránka představuje klub, jeho historii, současný tým, poslední výsledky a informace pro fanoušky. Obsah je z velké části načítán dynamicky pomocí **AJAX** z **JSON** souborů – například soupiska hráčů nebo přehled zápasů.  
Cílem projektu je vytvořit moderní, přehledný a responzivní web, který ukáže práci s daty, dynamickým obsahem a základní komunikací se serverem.

---

##  Cílová skupina
- fanoušci Arsenalu  
- lidé, kteří hledají základní informace o klubu  
- návštěvníci, kteří se zajímají o tým, hráče a výsledky  

---

##  Obsahové sekce webu

### 1. O klubu – Arsenal FC
Základní informace o klubu, tradice, úspěchy a hodnoty.

### 2. Historie klubu
Klíčové historické milníky, legendy klubu, nejdůležitější sezóny.  


### 3. Současný tým
Dynamicky načítaná soupiska hráčů – fotografie, pozice, číslo a krátký popis.  


### 4. Poslední výsledky
Zápasy z aktuální sezóny – skóre, soupeř, datum.  


### 5. Fan zóna
Informace o vstupenkách, atmosféře na Emirates Stadium a doporučení pro fanoušky.

### 6. Kontakt
Kontaktní údaje na správce webu + jednoduchý kontaktní formulář odesílaný přes PHP.

##  Návrh designu / wireframe
- Barevné schéma v klubových barvách (červená, bílá, tmavě modrá)  
- Jednotlivé sekce oddělené barevnými bloky  
- Grid pro karty hráčů (3–4 sloupce podle šířky obrazovky)  
- Moderní UI prvky (rounded, shadow, Tailwind CSS komponenty)  
- Hero sekce s logem Arsenalu a sloganem **„We Are The Gunners“**
